# Benchmark Mineral Intelligence

> IOSCO-assured price reporting agency and market intelligence provider for the lithium-ion battery and energy-transition supply chain. The Benchmark Prices API v2 exposes 36 read-only operations covering assessed prices, summaries and composite indices across 14 markets, from lithium and cobalt through cathode, anode, battery cells and black mass.

Generated by API Evangelist (apis.io) from the provider-published OpenAPI at https://www.benchmarkminerals.com/prices-api.yml. Benchmark does not publish an llms.txt of its own.

## API

- [API overview](https://www.benchmarkminerals.com/api): what the Prices API covers and how to get a key
- [API reference](https://www.benchmarkminerals.com/api/docs): rendered reference (client-side; the spec URL is in the page source)
- [OpenAPI 3.0.3 specification](https://www.benchmarkminerals.com/prices-api.yml): the machine-readable contract
- Base URL: `https://api.benchmarkminerals.com/v2`
- Authentication: API key in the `x-api-key` request header, retrieved from the subscription section of your account
- Shape: every operation is a POST carrying a filter object; the surface is read-only and has no pagination

## Agent surface

- MCP endpoint: `https://mcp.benchmarkminerals.com/mcp` (remote, OAuth 2.0 bearer; tools/list requires a token)
- OAuth protected-resource metadata: https://mcp.benchmarkminerals.com/.well-known/oauth-protected-resource
- OAuth scopes: `benchmark-tools/sandbox.read`, `benchmark-tools/production.read`
- Authorization server: https://mcp-auth.benchmarkminerals.com/oauth2/authorize (Amazon Cognito, eu-west-2)
